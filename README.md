# Health of Nations - play it

A turn-based strategy game about running a national health system, built as a health-economics teaching tool.

Play: https://austinhendersoneconomist.github.io/health-of-nations-play/

This repo hosts only the built game. Six years, two elections, one budget. Everyone wants everything.

Companion course: https://austinhendersoneconomist.github.io/health-of-nations-play/course/ (nine interactive chapters, *Health Economics, Interactive*). Each chapter ends with a classroom run, e.g. [`?assignment=a6`](https://austinhendersoneconomist.github.io/health-of-nations-play/?assignment=a6), that opens the game on a fixed seed so a whole class governs the same country.
